# Project 09 — Insurance Claims PEFT / LoRA / QLoRA

**Status:** Scaffold; implementation and tests not yet added.

## Objective
Prepare anonymized instruction examples and demonstrate parameter-efficient fine-tuning. Quantized training requires compatible hardware and versions of PyTorch, Transformers, PEFT and supporting libraries.

## Planned components
- Synthetic claims instruction data.
- JSONL validation and dataset splitting.
- Optional GPU notebook/script for LoRA/QLoRA.
- Base-versus-adapter evaluation and reproducibility notes.

A GPU may be required for actual fine-tuning. No real personal, medical or insurance claimant data should be committed.
