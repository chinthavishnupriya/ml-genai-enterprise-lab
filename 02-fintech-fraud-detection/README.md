# Project 02 — Fintech Transaction Fraud Scoring & Customer Segmentation

**Status:** Scaffold; implementation and tests not yet added.

## Objective
Build an interpretable Decision Tree fraud classifier, compare it with a Random Forest using metrics suitable for imbalanced labels (including ROC-AUC), and segment normalized customer profiles with K-Means. Choose K with Elbow and Silhouette Score analysis.

## Planned components
- Synthetic transaction and customer-profile data generator.
- Cleaning and train/test evaluation without data leakage.
- Decision Tree vs Random Forest comparison report.
- K-Means cluster profiles and plots.
- Tests and instructions for reproducing results.

Use only synthetic or appropriately anonymized data. Do not use demo results to make real financial decisions.
