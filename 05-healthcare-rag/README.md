# Project 05 — Healthcare Clinical Manual Ingestion & RAG

**Status:** Scaffold; implementation and tests not yet added.

## Objective
Ingest PDF, Markdown and text documents, chunk the content, embed passages, and retrieve relevant context for a query using a local vector index.

## Planned components
- Multi-format ingestion with source metadata.
- Fixed-size-overlap and heading-based chunking strategies.
- Local embeddings/vector index and retrieval evaluation.
- Tests and a small non-sensitive example corpus.

Educational information retrieval only; not a clinical decision tool. Do not add patient-identifiable information or treat generated text as medical advice.
