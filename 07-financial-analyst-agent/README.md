# Project 07 — Autonomous Financial Analyst Agent

**Status:** Scaffold; implementation and tests not yet added.

## Objective
Demonstrate an agent workflow that can invoke controlled tools such as a read-only SQL query, document retrieval, and calculator, then assemble a sourced response.

## Planned components
- SQLite sample account data and market outlook text documents.
- Typed tool interfaces and input validation.
- Agent execution trace (action/observation/result).
- Tool permission boundaries and tests.

Only synthetic financial data will be included. The demo is not investment, tax, or financial advice. SQL tools must be read-only and constrained.
