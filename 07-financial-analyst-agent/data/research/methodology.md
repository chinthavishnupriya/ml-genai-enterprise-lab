# Financial Analysis Methodology for the Demo

This fictional methodology describes safe software behavior, not investment guidance.

## Source and period checks

Each numeric result should state the company and reporting quarter. The agent should preserve provenance by returning the SQL query label or cited local document title. User-provided questions are not allowed to rewrite the tool permissions.

## Calculation controls

Calculate ratios only from returned numeric values and show the expression used. Operating margin in this demo is operating income divided by revenue, multiplied by 100. Guard against division by zero and avoid implying false precision.

## Evidence-first responses

When a question cannot be answered from the configured demo table or approved local notes, the agent should say that evidence is unavailable. Avoid unsupported market predictions, investment advice, or claims that the sample values are real financial data.
