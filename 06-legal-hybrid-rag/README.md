# Project 06 — Legal Contract Q&A with Hybrid Search

**Status:** Scaffold; implementation and tests not yet added.

## Objective
Combine BM25 keyword retrieval with dense vector retrieval, fuse ranks (for example with Reciprocal Rank Fusion), re-rank candidates with a cross-encoder, and ground answers in retrieved contract passages with citations.

## Planned components
- Local sample contracts and clause-number queries.
- BM25 and dense retrieval adapters.
- Rank fusion and optional re-ranking.
- Context recall/precision checks and citation validation.

This is a retrieval demonstration, not legal advice. Use only documents you have permission to process.
