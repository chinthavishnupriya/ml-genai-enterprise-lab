# Project 10 — Enterprise Agentic RAG Capstone

**Status:** Scaffold; implementation and tests not yet added.

## Objective
Integrate shipment-data ingestion, hybrid retrieval, tools/agent workflow, input/output safety checks and an evaluation harness inspired by RAGAS metrics.

## Planned components
- Synthetic shipment events and local logistics-policy corpus.
- Hybrid retrieval and controlled tool execution.
- Basic PII/prompt-injection checks and safe fallbacks.
- Faithfulness/relevance/context metrics where dependencies and evaluation data support them.
- End-to-end test suite and security limitations report.

This is a capstone demonstration, not a production logistics control system. Safety filters are not a guarantee against all attacks.
